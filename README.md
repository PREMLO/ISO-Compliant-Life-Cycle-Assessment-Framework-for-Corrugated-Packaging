ISO-Compliant Life Cycle Assessment Framework for Corrugated Packaging

An end-to-end Life Cycle Assessment (LCA) framework developed to evaluate the environmental footprint of corrugated packaging. The application follows ISO 14040 and ISO 14044 principles to analyze sustainability metrics and support environmentally responsible packaging decisions.

Project Overview

This project was developed to assess the environmental impact of corrugated packaging throughout its life cycle. The framework estimates carbon emissions, energy consumption, water usage, transportation impact, and waste generation using standardized methodologies. It provides an interactive dashboard that helps users compare different packaging alternatives and make data-driven sustainability decisions.

Features

• ISO 14040 and ISO 14044 compliant LCA workflow

• Interactive Streamlit dashboard

• FastAPI backend integration

• Carbon footprint calculation

• Energy and water consumption analysis

• Transportation emission estimation

• Packaging comparison

• Interactive charts and visualizations

• Sustainability performance evaluation
